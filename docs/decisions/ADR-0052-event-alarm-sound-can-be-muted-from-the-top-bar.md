# ADR-0052: 予定の通知の音を、画面の上部のボタンで消す・鳴らす

- 状態: 承認
- 日付: 2026-10-19
- 関連: task #520、ADR-0021（予定のアラーム）、ADR-0031（端末への通知）、ADR-0041（画面の中で知らせる）

## 背景

持ち主（2026-10-19）: 「カレンダー予定の通知で音がなるが、音を消したいときがある。音を鳴らしたいときもある」。
予定の通知の音は 2 か所から出る。WBS を開いている間の画面の中の呼び鈴（ADR-0041、WebAudio）と、端末への通知（ADR-0031、
端末の通知音）。設定の「画面の中で知らせる」を切ると表示ごと消え、端末への通知は端末の設定を開かないと音を消せない。

## 決定

- 画面の上部（打刻ボタンの右）に音のボタンを置く。押すたびに「鳴らす（既定）」と「消す」が入れ替わる。消しているときは
  音を消した印の色付きの絵にする。
- 消してあると、**予定の通知（`event_alarm`）だけ**を音なしにする。画面の中の知らせは表示と題名の点滅だけ、端末への通知は
  `silent: true` で出す。定常業務の開始・打刻の止め忘れ・締めの通知は今までどおり。表示そのものは消さない。
- 入り切りは端末ごと（localStorage、`inPageAlarm` と同じ判断）。Service Worker は localStorage を読めないので、画面が
  Cache Storage（`wbs-prefs` の `/__prefs/alarm-sound`）にも写す。殻の古い版を消す処理（`staleShellCaches`）は殻の名前だけを消すので、この写しは残る。

## 理由

- 「ときどき消したい・ときどき鳴らしたい」なので、設定の画面の奥ではなく、どの画面からも 1 回で切り替えられる所に置く。
- サーバに置く案は採らない。会議中の PC だけ消したい、のような端末ごとの使い分けになり、失われても既定（鳴らす）に戻るだけで困らない。
- 時間で自動で戻す（1 時間だけ消す）案は、頼まれていないので採らない。

## 影響

- スマホの wbstimer の予定のアラーム（端末の中で鳴らす。wbstimer ADR-0014）はこのボタンでは変わらない。
- `silent` を無視するブラウザ（音の扱いを OS に任せるもの）では、端末への通知は端末の設定どおり鳴る。
