# ADR-0014: タスクから予定を取る口と、タスクの「予定済みの時間」

- 状態: 承認
- 日付: 2026-10-01
- 関連: task #159（予定とタスクを結ぶ）・#157 / ADR-0013（カレンダー画面）・#158（週表示のドラッグ）・
  ADR-0009（予定の表と API。予定は `task_id` を持つ）・ADR-0010（残）

## 背景

予定は `task_id` でタスクに結べるが（ADR-0009）、結ぶ口は予定の編集画面のタスク欄だけだった。中長期の計画
（タスクの残）を日々の予定へ落とす口が要る。決めることは 4 つ: タスクの画面からカレンダーへ何で渡すか、
一覧から時間グリッドへ落としたときの長さ、予定の見た目、タスク側に出す「予定済みの時間」の数え方。

## 決定

### 「時間を取る」は URL のクエリで渡す

- タスクの一覧・タスク編集・ガントの行の「時間を取る」は `/calendar?schedule_task=<id>` へ移る。
  カレンダーはクエリのタスクを「時間を取る」の最中として持ち、週表示の空き枠を**押す**と既定の長さで、
  **引く**とその範囲で、そのタスクに結んだ単発の予定を**すぐ作る**（編集画面は開かない）。題名はタスク名、
  色は既定（＝タスクのカテゴリの色で描く）。作ったらクエリを外す。
- 週表示の横（狭い画面は上で折りたたむ）に「未完了・残がある」タスクを期限が近い順に並べる。押せば同じ
  「時間を取る」に入り、引いて時間グリッドへ落とせばその位置に予定を作る。
- 落とす操作はポインタイベントだけで追う（`draggable` は使わない。#158 と同じ）。マウスは 8px 動けば、指は
  300ms の長押しで引き始める。落とした位置 → 日と分は WeekView の印（`data-day-column`）から引く。

### 長さの既定は 1 時間、残が 1 時間より短ければ残

- 15 分へ切り上げ、最短 15 分。残が決まらない・0 のタスクでも 1 時間で作る（取ること自体は止めない）。
- 落とした開始は 15 分へ丸める（空き枠を引いて作る範囲は従来どおり 30 分単位）。

### 予定の色とタスク名

- 予定に色があればそれ。既定（`DEFAULT`）で `task_id` があれば、タスクのカテゴリの色で塗る（月・週・
  選んだ日の一覧）。予定の題名とタスク名が違えば、ブロックに「タスク: 名前」を添える。

### 「予定済みの時間」

- `TaskResponse.scheduled_hours` = **今日（利用者の日付）以降に始まる**、そのタスクに結ばれた回の長さの合計。
  繰り返しは回ごと（移した回は移した先、飛ばした回は数えない）。
- 今日の回は、もう過ぎたものも数える（「今日以降」の区切りを日で持つ。時刻で切ると、今日の作業が実績に
  入って残が減ったのと同時に予定済みからも消え、まだ取っていない分が日中に揺れる）。
- **終日の回は数えない**（その日に充てる印で、作業の時間ではない）。
- 終わりの無い繰り返しを数え切るため、先は今日から 365 日まで。
- 数えるのは**その利用者の予定だけ**（他人の予定がたまたま自分のタスクの id を持っていても数えない）。
- `unscheduled_hours` = max(残 − 予定済み, 0)。残は自分の残（ADR-0010 の `remaining_hours`）。残が決まらない
  ときは null。
- 計算は予定のユースケース（`CalendarEventUseCases.scheduled_minutes_by_task`）に置き、タスクのユースケースは
  口（`ScheduledTimeLookup`）越しに引く。口を渡さない呼び手（ダッシュボードなど）では null を返す。

## 理由

- クエリで渡すと、タスクの画面からの遷移・再読み込み・戻るでも同じ状態に戻れる。画面の内部状態や
  セッションに持つと、別のタブ・リンクの共有で途切れる。
- 押す・引くで**すぐ作る**のは、「計画 → 予定」を短い操作にするため。直したければ作った予定を開けばよく、
  編集画面を毎回挟む理由が薄い。
- 「予定済み」を保存しない（その場で展開して数える）。予定の書き込みのたびにタスクへ写すと、繰り返しの
  回・移動・飛ばし・日付の進みで値が古くなる。展開は予定 API の回と同じ道（`OccurrenceExpander`）を通るので、
  画面に出る回と数が食い違わない。

## 影響

- タスクの一覧・取得・作成・更新の応答に `scheduled_hours` / `unscheduled_hours` が増える。一覧のたびに、
  タスクに結ばれた予定を 365 日ぶん展開する（結ばれていない予定は展開しない）。
- 祝日などで営業日シフトする繰り返しは、シフト後の日で数える（回の展開と同じ）。
- 作った予定は元に戻す・やり直しの履歴に入れない（ドラッグの移動・伸縮だけが対象。ADR-0013 のまま）。
- 子を持つタスクの予定済みは自分に結ばれた予定だけ（子の分は積み上げない）。
