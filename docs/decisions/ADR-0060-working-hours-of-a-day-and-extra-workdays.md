# ADR-0060: その日の稼働時間（残業・休日出勤）と、プロジェクトの稼働日

- 状態: 承認
- 日付: 2026-10-20
- 関連: task #558（親 #552）、ADR-0058（終わる見込み）・ADR-0059（プロジェクトのカレンダー・人のカレンダー）

## 背景

持ち主（2026-10-20）「休日出勤は？」→「足す、あと、OFF,HALF はいいけどカスタムも追加してほしい」「カスタムは稼働時間が決められる」
「残業も可」「各メンバーのカレンダーはプロジェクトのカレンダーを継承して作って」「カレンダー作るというか、UI 上はそう表示して」。

ADR-0059 の人のカレンダーは時間を減らす向き（休み・半休）だけで、稼働しない日に働くことも、いつもより長く働くことも表せない。

## 決定

### 1. 人のカレンダー: その日の稼働時間（カスタム）

- 各人の休み（`member_days_off`）に **`hours`（その日の稼働時間。0〜24、空可）** を足す。入っていれば休む割合（`off_percent`）は見ない。
  - 1 日の工数より多ければ残業、少なければ短い日、0 なら休み。
  - **稼働しない日（土日・プロジェクトの休日）に入れれば休日出勤**。その日は、その人のどのタスクも進む。
- その日に使える時間 = `その日の稼働時間 × 従事率`（1 日の工数の代わりに使う）。人に付き、プロジェクトをまたいで同じ（ADR-0058 決定 2 と同じ）。
- 休み・半休（`off_percent`）は今までどおり。休み・半休を入れ直すと `hours` は消える。

### 2. プロジェクトの稼働日

- 表 `team_extra_workdays`（プロジェクト・日付・名前）: **稼働しない曜日に、そのプロジェクトで働く日**（チーム全員の休日出勤）。
- 休日と同じく、どのプロジェクトにも付き、下のプロジェクトは引き継ぐ。**同じ日に休日と稼働日があれば、近いプロジェクト（自分 → 親 → 根）の指定が勝つ**
  （子で、親の休日を稼働日にも、親の稼働日を休日にもできる）。同じプロジェクトの同じ日には並べない（入れると片方を消す）。
- 組み方は Domain の `layer_calendar_days`（`src/domain/services/project_calendar.py`）1 か所。カレンダーの画面と見込みの計算の両方が使う。

### 3. 見込みの計算

- タスクが進むのは、**そのタスクのプロジェクトのカレンダーで働く日**か、**担当者がその日の稼働時間（> 0）を決めた日**。
- その日の担当者の時間は、稼働時間を決めた日はそれ × 従事率、ほかは 1 日の工数 × 従事率 ×（100 − 休む割合）。
  その日に進めないタスクの分は、同じ人のほかのタスクへ回る（ADR-0059 決定 1 と同じ）。

### 4. 画面: 人のカレンダーはプロジェクトのカレンダーを引き継いで見せる

- データは人ごとの違いだけを持つ（人ごとにカレンダーを複製しない）。画面では、プロジェクトのカレンダー（曜日・休日・稼働日）を下敷きに出し、
  その上にその人の違いを重ねて「この人のカレンダー」として見せる。
- 日を押すと小さなメニュー: 働く日は「休み（終日）」「半休」、働かない日は「出勤（1 日の工数）」、どちらにも「稼働時間を決める…」
  （時間を打つ。多くても少なくても 0 でもよい）と、違いがあれば「プロジェクトのカレンダーどおりに戻す」。
- 日の下の言葉: 休み・半休・休 N%・N h（短い日）・残業 N h・出勤 N h。引き継いだものは薄い字か「稼働日」。
- プロジェクトのカレンダーは、日を押すと、ふだん働く日は休日に、働かない日（土日・親の休日）は稼働日になる。ここで足した日を押すと戻る。

## 理由

- **稼働時間を時間で持つ**のは、持ち主の言う「カスタム＝稼働時間を決める」で、残業（いつもより多い）も表せるから。割合で持つ案は、
  1 日の工数がプロジェクトごとに違うと「10 時間働く」を言い表しにくい。
- **人ごとにカレンダーを複製しない**のは、プロジェクトの休日を直したときに全員のものを直し直す必要が出るから。重ねる形なら、
  プロジェクト側の変更がそのまま全員に効く。
- **近いほうが勝つ**のは、子のプロジェクトだけ祝日に働く・親の稼働日に子だけ休む、を両方表せる最も短い決まりだから。

## 影響

- 移行 `0028`: `member_days_off.hours`、表 `team_extra_workdays`。今の行は `hours` が空（今までどおり）。
- `GET /api/projects/{id}/calendar` は `extra_workdays`（休日と同じ形）と、休みの `hours` を返す。
  `POST/DELETE /api/projects/{id}/calendar/extra-workdays`、`POST /api/projects/{id}/members/{user_id}/leave` は `hours` を受ける。
- ガントの日の列は、task #559 からプロジェクトのカレンダー（休日・稼働日）で塗る（表示しているプロジェクトのもの。下のプロジェクトだけの日はその行だけ）。
  人ごとの稼働時間はガントの列には映さない（行は人ではなくタスク）。
