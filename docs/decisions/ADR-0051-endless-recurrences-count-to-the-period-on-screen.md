# ADR-0051: 終わりの無い繰り返しは、予定済みの時間に「画面の期間の終わり（無ければ今月末）」まで数える

- 状態: 承認
- 日付: 2026-10-17
- 関連: task #434、ADR-0014（「予定済みの時間」。その「先は今日から 365 日まで」を、終わりの無い繰り返しについてだけ置き換える）

## 背景

ADR-0014 は、終わりの無い繰り返しを数え切るため、予定済みの時間を今日から 365 日先まで数えていた。
「15 分 × 毎平日」の定常業務を作ると予定済みが 65.25h、「週 2 回 1 時間」の定例会が 104h になり、
残（数時間〜数十時間）を必ず上回って「まだ取っていない分」が 0 に張り付く。予定済みと残を比べる、
という数字の目的に合わない。

## 決定

- **終わりの無い繰り返し**（終了日を決めていないもの）の回は、今日から**画面で選んでいる期間の終わり**まで数える。
  期間を持たない画面（タスク一覧・タスクの編集・今日・実績）は**今月末**（利用者の日付）まで。
- 期間を持つ画面（カレンダー）は `GET /api/tasks?scheduled_until=<見ている範囲の終わり>` で渡す。
- 単発の予定と、終わりのある繰り返しの数え方は変えない（今日から 365 日先まで）。

## 理由

- 終わりの無い繰り返しには「全部」が無いので、どこかで区切るしかない。365 日は「数え切る」ための数字で、
  残と比べる意味を持たない。区切りを利用者が見ている範囲に合わせれば、カレンダーで見えている回の合計と一致する。
- 今月末を既定にしたのは、締めが月 2 回で、計画の見直しも月の単位で行うため。
- 採らなかった案: 終わりの無い繰り返しを数えない（定例の会議に結んだタスクが常に「予定なし」に見える）・
  区切りを設定にする（定常の操作を設定にしない）。

## 影響

- 同じタスクでも、カレンダーと一覧で予定済みが違うことがある（見ている範囲が違うため）。
- 終わりのある繰り返しは、今月を越えても今までどおり全部数える。
