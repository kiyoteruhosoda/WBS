# ADR-0042: PC の自動記録は送り手の ID 付きでまとめて送り、1 区間ずつ結果を返す

- 状態: 承認
- 日付: 2026-10-13
- 関連: task #379（WBS 側の受け口）・#377（WinTrack）、ADR-0018（Bearer の口と押した時刻の範囲）、
  ADR-0008（打刻は下書き）・ADR-0012（締めた期間は書き換えない）

## 背景

Windows の自動記録ツール WinTrack は、PC の前で作業した区間を手元で規則に当ててタスクに割り当て、
まとまった区間を WBS の打刻として送る。PC は寝る・電波が切れる・応答を受け取り損ねるので、
**同じ区間を何度送っても 1 本にしかならない**こと、**1 本がだめでも残りは入る**ことが要る。
これまでの手の追加（`POST /time-entries`）は Web のログインだけで、1 本ずつ・失敗は 4xx で返す。

## 決定

1. 口は `POST /api/time-entries/auto`。Bearer を通す（`AppOrWebUserDep`、ADR-0018 と同じ）。1 回に 1〜200 区間。
   表題やアプリ名は受け取らない（区間・タスク・送り手の ID だけ）。
2. 区間ごとに送り手（WinTrack）が付けた ID `client_ref`（UUID）を持たせ、`time_entries.client_ref`
   （NULL 可・`(user_id, client_ref)` で一意の索引 `uq_time_entries_client_ref_per_user`）に入れる。
   出どころは `source = "auto"`。
3. 応答は 200 で、送った順に 1 区間ずつ `status` を返す。判定の順は
   **送り直し（`duplicate`）→ 範囲とタスク（`invalid`）→ 締め（`closed`）→ 重なり（`overlap`）→ 作る（`created`）**。
   - `duplicate` は既にある打刻をそのまま返し、中身が違っても上書きしない（送り直しの判定は ID だけ）
   - `invalid` の範囲は押した時刻（ADR-0018）と同じ: 60 秒までの未来は「今」に寄せ、それより先と 7 日より前は断る。
     秒未満は落とす。寄せた結果で長さが無くなった区間も断る
   - `overlap` は走っている打刻を「終わりが無い」として数える（走らせている間の自動の区間は入らない）。
     同じ回の中で先に作った区間とも重ならない
   - 理由は `error` に短い語で返す（`ended_not_after_started`・`in_future`・`too_old`・`task_not_found`・
     `period_closed`・`overlaps_time_entry`）
4. 1 区間ずつ確定（commit）する。同じ区間を同時に送り直して一意の索引に当たったときは、先に入った方を
   `duplicate` で返す。
5. 画面は「今日」の打刻の一覧と締めの画面の打刻に「自動」の印を付ける。作った後は手の打刻と同じに直せる。

## 理由

- **ID で見分ける**: 始まりと終わりで見分けると、送り手が区間を伸ばして送り直したときに 2 本になる。
  送り手の ID なら、中身が変わっても同じ区間と分かる（上書きしないのは、利用者が WBS で直した後の送り直しで
  直したものを戻さないため）。
- **1 区間ずつの結果**: 全体を 4xx にすると、1 本の重なりで残りの 199 本が入らず、送り手は何度送っても進まない。
  件ごとの結果なら、送り手は `created` と `duplicate` を送り終わりとして手元から消し、ほかは手元で見せられる。
- **重なりは断る（寄せない）**: 自動の区間を手の打刻に合わせて削ると、利用者の知らない形の打刻ができる。
  断れば、送り手の手元に残って利用者が判断できる。
- 採らなかった案: 区間ごとに `PUT /time-entries/auto/{client_ref}`（1 区間 1 往復で、溜めた区間を送るのに遅い）。

## 影響

- `time_entries` に列と索引が 1 つずつ増える（移行 0017）。手の打刻は `client_ref` が NULL のまま。
- `APP_CLIENT_IDS` に WinTrack の client_id を足すまで、Bearer では通らない（配布の設定。deploy-repo）。
- 規則（#381）と更新の中継（#384）は別の ADR。
