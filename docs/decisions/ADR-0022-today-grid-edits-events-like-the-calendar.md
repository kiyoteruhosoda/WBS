# ADR-0022: 「今日」の時間グリッドで予定を作る・動かす・直す

- 状態: 承認
- 日付: 2026-10-01

## 背景

「今日」の画面（ADR-0015）の時間グリッドは、カレンダーの週表示（`WeekView`）を 1 日分で描いているが見るだけで、
予定を入れるにはカレンダーへ移る必要があった。持ち主の依頼（2026-10-01、task #185）は「ダッシュボードから今日の
予定も入れたい」。

カレンダーの書き込み（ドラッグで動かす・伸ばす、元に戻す・やり直し、編集画面・削除の確認、409 の扱い。ADR-0013）は
`CalendarPage` の中に直に書かれていて、ほかの画面からは使えなかった。

## 決定

- カレンダーの書き込みと、そのための画面（`EventEditDialog`・範囲の確認・削除の確認・知らせ）を
  `components/calendar/useCalendarEditing.tsx` に移し、カレンダーと「今日」の両方がそれを使う。
  編集画面の項目には手を入れない（同じものを開くだけ）。
- 「今日」のグリッドにカレンダーの週表示と同じ操作を付ける: 空き枠をドラッグ（指は長押しから）で範囲を選ぶと
  その範囲で編集画面を開く、空き枠をタップするとその時刻（:00 / :30）で開く、予定を引いて動かす・端を引いて
  伸ばし縮める、元に戻す・やり直し（グリッドの見出しのボタン）。指の扱いは `useWeekDrag` のまま。
- 予定を**押したら編集画面を開く**。カレンダーは押すと選んで下に日の一覧を出し、二度押しで編集するが、
  「今日」には日の一覧が無いので、押すだけで開く。削除は編集画面から。
- グリッドの見出しに「予定を作る」を置く（カレンダーの日の一覧の「予定を作る」と同じ文言）。今の後で、時刻のある
  予定と重ならない最初の 15 分刻み（長さは編集画面の既定の 30 分）で開く（`todayView.nextFreeStartMinute`）。
- 予定を書いたあとに読み直させるものを `calendar/calendarQueries.ts` の 1 か所にまとめ、回・祝日に加えて
  タスク（予定済みの時間）と「今日」の要約（まだ時間を取っていないタスク）も読み直させる。カレンダーでも同じ。

## 理由

- 書き込みを複製すると、楽観ロック（版）・履歴の捨て方・409 の扱いが 2 か所でずれていく。フックに移せば
  カレンダーの挙動はそのままで、「今日」は呼ぶだけになる。
- 押して編集にしたのは、選んだだけでは何も起きない画面になるため（日の一覧が無い）。カレンダーに日の一覧を
  足す案は、狭い画面でグリッドの高さを削るので採らなかった。
- 「予定を作る」の開始を今の後の空きにしたのは、「今日」の画面から入れる予定はこれからのものだから。9:00 固定
  （カレンダーの既定）では、午後に開くと過ぎた時刻で開く。
- 読み直しの範囲を広げたのは、「今日」の要約の「まだ時間を取っていないタスク」がタスクに結んだ予定で変わるため。
  カレンダーで編集画面からタスクを結んだときも、これまではタスクの予定済みの時間が古いまま残っていた。

## 影響

- `CalendarPage` は書き込みのコードを持たなくなった（タスクから作る口（task #159）だけを持つ）。
- 予定を書くたびにタスクの一覧と「今日」の要約も取り直す（問い合わせが少し増える）。
- 「今日」のグリッドの上に見出しの行（約 44px）が増え、グリッドの見える高さはその分減る。
