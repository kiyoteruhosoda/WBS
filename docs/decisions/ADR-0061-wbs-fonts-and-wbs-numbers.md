# ADR-0061: WBS の字と印（見出しの字・WBS 番号と枝の罫線）

- 状態: 承認
- 日付: 2026-10-21
- 関連: task #549（決定）・#639（実装）、ADR-0057（色と図柄）、
  Tracker（forge `kyon/nolumiatracker`）の ADR-0065・Scheduler（forge `kyon/nolumiascheduler-server`）の ADR-0059

## 文脈

WBS・Tracker・Scheduler は同じ作りから分かれたので、色と図柄（ADR-0057）を変えても画面の手触りが同じだった。
#549 で見本を並べ、持ち主が「字」と「その道具だけの印」を選んだ（2026-10-21「はい」。見本 https://claude.ai/artifact/6hj6a4MTADvZqefgLbh1ha）。

## 決定

1. **見出しの字は Zen Kaku Gothic New**（太い角ゴシック）。上の帯の画面名・メニューのアプリ名・一覧の束（プロジェクト）の名前・ガントの見出し・MUI の h5/h6。
   本文は Noto Sans JP のまま。
2. **WBS 番号と日付は IBM Plex Mono**（等幅で桁がそろう）。番号・ガントの日付の目盛り・開始と期限・一覧の期限。
3. **印は WBS 番号と枝の罫線。** タスクの一覧（プロジェクトで束ねた表）とガントの左の表で、題名の前に `1.3.2` のような番号を置き、
   親から子へ細い線（主色を 55% の濃さ）を引く。
   - 番号: 最上位のプロジェクトを木の順に 1・2…。プロジェクトの下は、一覧の並びと同じく直のタスク（作った順＝id）→ 子のプロジェクト（木の順）で
     1 本の通し番号。子タスクは親の番号の下に `.n`。未分類のタスクには付けない。
   - 番号は絞る前の一覧で決める。並べ替え・絞り込みでは変わらない（タスクやプロジェクトを足す・消すと後ろの番号は詰まる）。
   - ガントは始まりの順のまま、子タスクを親の直後へ寄せて線でつなぐ。束ねない一覧は線を引かず、番号と「↳」だけ。
4. 字は Google Fonts から読む（Noto Sans JP と同じ）。

## 影響

- 番号は表示だけで、保存しない（API は変えない）。
- 上の帯（高さ 58px・白）と左のメニューは今のまま。見本の「色の帯 48px・下のメニュー」は #639 では入れていない。
