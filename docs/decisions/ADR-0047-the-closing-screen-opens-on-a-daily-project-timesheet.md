# ADR-0047: 締めの画面は「日ごと × プロジェクト」の工数表から始める

- 状態: 承認
- 日付: 2026-10-13
- 関連: task #389（持ち主の要望）、ADR-0012（締め）・ADR-0026（プロジェクト別の合計）・ADR-0036（締めの画面の操作）、
  ADR-0045（自動の打刻）

## 背景

締めで見たいのは「どのプロジェクトに、どの日、何時間」と「その日の業務の開始と終了」。これまでの締めの画面は
打刻の時間グリッドが主で、合計の表はその下にあった。

## 決定

1. 締めの画面は**工数表**から始める（表示は「工数表」と「時間の表」を切り替え。端末に覚える）。
   - 行はプロジェクト（タスクの合計）。名前の下にプロジェクトコード（`projects.code`。欄は既にある）。行の束ね方は
     プロジェクト別の合計（ADR-0026）と同じで、サイドバーの範囲に従う（範囲が全部なら最上位のプロジェクトへ子孫の分まで積む）
   - 列は期間の日。行と日の計
   - いちばん上の行に、その日の**業務の開始**（最初の打刻の始まり）と**終了**（最後の打刻の終わり）。休憩は差し引かない
   - 時間は **0.5 時間単位に丸めて見せる**（中身は秒のまま。計は丸める前の秒を足してから丸める。正確な長さは吹き出し）
   - WinTrack の自動の打刻を含むセルに点の印
2. セルを押すと、その日・その行の打刻の一覧が開き、1 本ずつ直す窓（今までと同じ）へ進める。分ける・つなぐ・
   まとめて割り当てる・予定どおりにする、は「時間の表で見る」で今までの時間グリッドへ回す（その打刻を目立たせる）。
3. 気付かせる物（未割当・止め忘れ・重なり・打刻の無い予定）は工数表の横にも出し、押すと時間の表へ移って目立たせる。
4. サーバーは変えない（工数表は締めの画面の応答の打刻と日ごとの合計から組み立てる）。
5. 休みの行は task #392 で、業務の開始・終了の行の下に入れる。

## 理由

- 時間グリッドをやめずに切り替えにしたのは、分ける・つなぐ・ドラッグで直す操作がグリッドにしか無く、締めの
  補正にはまだ要るため。
- 丸めを 0.5 時間にしたのは持ち主の要望（工数の報告の単位）。確定（`work_logs`）は丸めない（ADR-0012 のまま）。

## 影響

- 合計の表（タスク別・プロジェクト別）は時間の表の下にだけ出す（工数表がプロジェクト別を兼ねる）。
