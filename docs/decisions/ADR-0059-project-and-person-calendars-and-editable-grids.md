# ADR-0059: プロジェクトのカレンダー・人のカレンダーと、セルを直接書き換える一覧

- 状態: 承認
- 日付: 2026-10-20
- 関連: task #557（親 #552）、ADR-0058（終わる見込み）・ADR-0055（メンバーは根に）

## 背景

#552 のあとに持ち主から 2 つの要望が来た（#552 のコメント、2026-10-20）。

- 「従事率とアサイン比率ってどこに設定？ MS Project みたいに一覧で簡単に入れたい」
- 「User ごとのカレンダーってどこ？ そしてプロジェクトのカレンダーもほしい」

ADR-0058 で入れたのは、メンバーの画面の欄（1 日の工数・従事率。1 人ずつ欄を離れると保存）、「稼働日と休み」の画面
（根のプロジェクトの稼働する曜日・休日と、各人の終日の休みを日付で足す）、タスクの編集画面のアサイン比率だけだった。
MS Project の「リソースシート」「ガントの左の表」「プロジェクトのカレンダー」「リソースのカレンダー」にあたるものが無い。

## 決定

### 1. プロジェクトのカレンダー: 今の「チームの休日」を広げる（置き換えない）

- **稼働する曜日は根に 1 つ**（今の `team_workweeks` のまま）。子のプロジェクトは根の曜日を使う。
- **休日はどのプロジェクトにも付けられる**（今の `team_days_off` の `project_id` に、根でないプロジェクトも入れてよくする）。
  あるプロジェクトの休日 = **自分の休日 ＋ 親・その親…根までの休日**（引き継ぐ。子で親の休日を消すことはできない）。
- 見込みの計算（ADR-0058 決定 3）:
  - 根の休日は今までどおり、担当者 × 根の「枠」の空きを 0 にする。
  - **根でないプロジェクトの休日**（自分と、根を除く先祖のもの）は、**そのプロジェクトのタスクだけ**その日は進めない。
    同じ人のほかのプロジェクトのタスクは進む（その日の時間はほかへ回る）。
- 入れられるのは根の管理者だけ（今と同じ）。日本の祝日の取り込みは、開いているプロジェクトに足す。
- 根を別の木の下へ移すとき: 曜日は捨てる（移った先の根のものを使う）が、**休日はそのプロジェクト自身の休日として残す**。
  下のものを根へ出すとき: 元の先祖の曜日と休日を自分へ写す（見込みを変えない。今と同じ）。
- 表の名前（`team_workweeks`・`team_days_off`）は変えない。**今の行は根の休日としてそのまま効く**ので、移すものは無い。
- API は `/projects/{id}/team-calendar` を `/projects/{id}/calendar` に改める（使うのは WBS の画面だけ）。応答の休日には
  付いているプロジェクト（`project_id`）を入れ、画面は親から引き継いだものを「親から」と分けて出す。

**置き換え（プロジェクトのカレンダーという別の表を作り、今の休日を写す）を選ばなかった理由**: 今の表で形が足りており、
写すと移行の間に二重に数えるおそれだけが増える。

### 2. 人のカレンダー: 休みに「どれだけ休むか」を持つ

- 各人の休み（`member_days_off`）に **`off_percent`（休む割合。1〜100、既定 100）** を足す。終日 = 100、半休 = 50。
  その日に使える時間 = `1 日の工数 × 従事率 × (100 − off_percent) / 100`。
- 今の行は終日（100）になる（移行 `0027`）。人に付く（プロジェクトをまたいで同じ）・持つのは日付と割合だけ、は変えない。
- 入れる場所は人の一覧の行の「カレンダー」から開く月の暦。日を押すたびに「終日 → 半休 → なし」と切り替わる。
- 「その日だけの工数」（時間で入れる）は持たない。半休より細かいものが要れば `off_percent` を画面から選べるようにする。

### 3. 一覧の入力: セルを直接書き換える一覧を自前で 1 つ作る

対象は 2 つ。

- **人の一覧**（メンバーの画面。MS Project のリソースシート）: 行 = メンバー、列 = 名前・役割・1 日の工数・従事率・
  1 日に使える時間（読むだけ）・カレンダー（開く）
- **ガントの左の表**: 行 = タスク、列 = タスク名（読むだけ）・担当・アサイン比率・残り時間・開始・期限・見込みの終わり（読むだけ）。
  行の高さを右の帯とそろえる。

操作（表計算と同じ）:

- 矢印で選ぶセルを動かす。選んだセルは太い枠で見える（焦点が見える）。
- 文字を打つか Enter・F2 で書き換えを始める。**Enter で確定して下へ、Tab で確定して右へ（Shift+Tab で左）**、Esc でやめる。
  確定したらその場で保存する（保存のボタンは無い）。Delete で空にできる列は空にする。
- **貼り付け**: 表計算からコピーした行と列（タブ区切り）を、選んだセルを左上として当てはめ、セルごとに保存する。
  読めない値・直せないセルは飛ばして、何件入れて何件飛ばしたかを出す。
- 直せないセル（権限が無い・読むだけの列）は選べるが書き換えは始まらない。

部品の選び方（2026-10-20 に持ち主が選んだ。おすすめの案）:

| 案 | 書き換え・Enter・Tab | 複数行の貼り付け | ガントの帯との行合わせ | 費用・重さ |
|---|---|---|---|---|
| **A. 自前の小さな一覧（MUI の部品の上に作る）** | 作る | 作る | そろう（同じ高さの行を自分で並べる） | 追加の部品なし |
| B. MUI X DataGrid の無料版（MIT） | ある | **無い**（Premium だけ。自前で足す） | 行の高さは合わせられるが、上下のスクロールを右の帯とつなぐのが手間 | 約 300KB 増える |
| C. MUI X DataGrid Premium | ある | ある | B と同じ | 年ごとの利用料 |
| D. AG Grid Community | ある | 無い（Enterprise だけ） | B と同じ | 重い・見た目が別物 |

**A を選ぶ**。要る操作は上の数個だけで、2 つの一覧で同じ部品を使い回せ、ガントの帯と同じ行の高さで並べられる。
見た目は今の WBS の色・文字のまま（デザイン案 #549 とぶつからない）。並べ替え・絞り込み・列の幅の変更は持たない
（要るなら B へ移る）。

## 影響

- 移行 `0027`: `member_days_off.off_percent` を足す。
- `GET /api/projects/{id}/calendar` は休日に `project_id` と `inherited` を返し、休みに `off_percent` を返す。
  `POST /api/projects/{id}/members/{user_id}/leave` は `off_percent` を受ける。
- 見込みの計算は `WorkSeat.leave` が日付 → 休む割合になり、葉のタスクに「そのプロジェクトの休日」を持たせる。
- 画面: 部品 `EditableGrid`（`frontend/src/components/grid/`）、人の一覧（メンバーの画面）・人のカレンダー・
  プロジェクトのカレンダー（今の「稼働日と休み」の画面）・ガントの左の表。
