# ADR-0040: 画面の中のアプリの像は favicon.svg をそのまま使う

- 状態: 承認
- 日付: 2026-10-07

## 文脈

タブ・ホーム画面のアイコンは `scripts/generate_pwa_icons.py` 1 本から作る（ADR-0028。図柄は WBS の木）。
一方、ログイン画面とメニューの上の像は画面のコードに書いた別の絵（青い箱にチェックマーク）で、
タブのアイコンと違って見えた。図柄を変えるたびに画面側の直しが漏れる。

## 決定

画面の中の像は部品 `AppMark`（`frontend/src/components/AppMark.tsx`）に寄せ、絵は持たずに
`favicon.svg` を `<img>` で読む。雛形 fastapitemplate の ADR-0053 と同じ作り。

## 理由

- 正本が生成スクリプト 1 本になり、図柄や色を変えると全部の場所がいっしょに変わる。
- favicon はベクタ（SVG）なので、30px のメニューでも 44px のログイン画面でもそのまま縮められる。
  角丸と地の色も絵の側に入っているので、画面側で箱を描き直す必要もない。
- 採らなかった案: 図柄を React の部品として書き、生成スクリプトがそれを読む形。正本が TS と
  Python の 2 か所に割れる。

## 影響

- 像を足す場所が増えても、絵を書き起こさず `AppMark` を使う。
- 画面の像だけを違う絵にすることはできない（したいなら、それは別の決定として ADR を書く）。
